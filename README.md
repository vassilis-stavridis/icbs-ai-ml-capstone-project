# Imperial College Business School — AI & Machine Learning Capstone Project


## NON-TECHNICAL EXPLANATION OF YOUR PROJECT
This repository contains the end-to-end implementation of the capstone project for the Imperial College Business School, Professional Certificate in Machine Learning and Artificial Intelligence.

This capstone project is a machine learning challenge modelled directly on real-world, high-stakes data science competitions (such as those hosted on Kaggle, NeurIPS, and DrivenData). Specifically, it is based on the NeurIPS 2020 Black-Box Optimisation (BBO) challenge, mirroring the complex parameter-tuning problems that frequently arise in professional machine learning environments.

The task is to build and optimise an ML model within a simulated "black-box" environment by observing how different inputs produce outputs, whilst the inner workings and exact evaluation metrics are hidden from view. The process involves making iterative, evidence-based improvements rather than relying on direct visibility into the underlying code.
